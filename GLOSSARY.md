# athaeck.de Portfolio

Personal portfolio of Nick Philipp Häcker: presents game and full-stack work to recruiters, studios and employers, in English and German.

## Language

### Projects

**Project**:
A single piece of work shown on the site (game, film, paper, tool, asset).
_Avoid_: Portfolio item, work, reference

**Project page**:
The detail page of one Project: role, tech, problem, media, links; the place an Embed lives.
_Avoid_: Case study, detail view

**Embed**:
An interactive Unity WebGL build (scene or game) running inside a Project page.
_Avoid_: Demo, iframe game, 3D scene

**Featured project**:
A Project the site leads with; the owner curates which Projects are featured and in what order.
_Avoid_: Highlight, top project

**Archive**:
Every Project that is not a Featured project, shown in compact form.
_Avoid_: More work, other projects

**Kind**:
The one broad class a Project belongs to: game, research, tool, film or asset.
_Avoid_: Category, type

**Genre**:
A short free description of what a Project is within its Kind, e.g. asymmetric co-op puzzle game or Blender add-on.
_Avoid_: Subtitle, subcategory

**Phase**:
One stretch of a Project's history with its own context, team size and the owner's role, e.g. a team course followed by a solo thesis.
_Avoid_: Stage, iteration, version

**Skill**:
A technology, method or platform (e.g. Unity, Scrum, AR) the owner backs with Projects or CV entries.
_Avoid_: Competence, technology

### Site

**Game mode**:
An optional, desktop-only way through the site's content as a playable world; it sits on top of the site's pages and never replaces them.
_Avoid_: Game world, playable portfolio, mobile mode

**Signature moment**:
The one playful moment with game character on the site's pages; it works without the Game mode and points towards it.
_Avoid_: Easter egg, gimmick, hero animation

### Person

**CV**:
The owner's career record, shown as the CV page and offered as the downloadable CV PDF.
_Avoid_: Resume, Lebenslauf

**CV entry**:
One station of the CV, of kind work, education, volunteering or achievement.
_Avoid_: Position, station, milestone

**Achievement**:
A CV entry for an award, showcase, certificate or participation; it may point to the Project it concerns.
_Avoid_: Award (as the umbrella term), honour

**Profile**:
The owner as a person: bio, contact, portrait, languages, interests, Services and what they are working on now.
_Avoid_: About (that is a page), vCard

**Service**:
One discipline the owner offers, e.g. Game Programming or Narrative Design.
_Avoid_: "What I'm doing"
